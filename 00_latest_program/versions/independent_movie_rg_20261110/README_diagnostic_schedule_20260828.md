# 分级诊断版本说明（2026-08-28）

这个版本用于高分辨率 Rainy-Bénard 算例的长时间运行。原来所有诊断都
由 `TPIN` 同时触发，完整力平衡和涡旋条件力平衡会显著拖慢时间推进。

默认诊断间隔为：

| 诊断组 | 默认间隔 | 主要输出 |
|---|---:|---|
| 普通统计 | 0.5 | `avgvar`、动能、Nu、m-prime 等常规时间序列 |
| 尺度/结构诊断 | 1.0 | `lm`、`lc`、MSE 尺度、结构识别 |
| 完整力平衡 | 5.0 | `force_balance_z.out`、涡旋条件力平衡 |

这样 (t=1000) 的诊断调用次数大约降为原来的 1/5（力平衡）和 1/10
（尺度诊断），目标是把高分辨率生产算例控制在约两三天量级；实际时间
仍取决于网格、MPI 核数和文件系统吞吐。

## `bou.in` 的可选设置

movie/涡旋控制行保持五列：

```text
mov_zcut_k  tframe_me  stat_me  vortex_lc  vortex_q_z
```

诊断间隔改为后面的独立段：

```text
!---------- Diagnostic output intervals --------------!
TSTAT_DIAG  TSCALE_DIAG  TFORCE_DIAG
0.5d0       1.0d0        5.0d0
```

例如：

```text
37  1.0  1  0.0  0.7
!---------- Diagnostic output intervals --------------!
TSTAT_DIAG  TSCALE_DIAG  TFORCE_DIAG
0.5d0       1.0d0        5.0d0
```

旧五列和旧八列格式仍然兼容；没有独立诊断段时自动使用 `0.5, 1.0,
5.0`，旧八列的后三列作为兼容回退。`TPIN` 仍保留在前面的输入行中以
保证旧文件可读，但新程序的三组诊断由上述独立段控制。

## `F_T` 的定义

`force_balance_sample` 在普通统计采样时保存最近一次速度差：

```text
F_T(t) = [u(t)-u(t-Δt_stat)] / Δt_stat
```

完整力平衡虽然每 5 个时间单位输出一次，但使用的是最近的普通统计间隔
速度差，不会把 5 个时间单位的有限差分误标成瞬时非定常项。首次采样后
需要一个前一时刻样本，因此第一个可用的 `F_T` 可能为空或从第二个普通
统计样本开始出现。

## 编译和部署建议

不要覆盖正在运行的旧 `simexec`。编译成功后使用独立名字，例如：

```text
simexec_diag05
```

先在短测试目录检查启动、普通统计频率、力平衡频率和续算，再复制到新
提交的 `run/` 目录。当前源程序和旧可执行文件应保留为回滚版本。

曙光编译时使用并行 HDF5 包装器：

```text
$HOME/software/hdf5-1.10.5-impi2017/bin/h5pfc
```

平台自带的 `mathlib/hdf5/1.8.20-intel-2017` 只有 `h5fc`，不能代替
并行 HDF5 的 `h5pfc`。可执行编译脚本为
`compile_shuguang_diag05.sh`；由于原 Makefile 的模块依赖不完整，脚本
采用串行编译，不影响最终 MPI 并行运行。
