# Independent movie and geostrophic residual (2026-11-10)

`TFRAME` in the time row sets 3-D cadence. Movie-control row column 2 `TSLICE` sets 2-D cadence. The first movie-control value is the 1-based z-cut level. Frame names use nint(time/TSLICE), preventing overwrites. Missing/nonpositive TSLICE falls back to TFRAME.

The horizontal z-cut includes `Qvap` and `Mprime = b + gamma*q - horizontal mean`; x-cut and z-cut also include velocities. The present cases use grid 385x385x65, z-cut level 43 (z/H about 0.69377).

`avgvar.out` column 11 is the instantaneous ratio of existing bulk diagnostics: the depth average of plane RMS of horizontal Fc+Fp divided by depth average of plane RMS of Fp, over 0.1<=z/H<=0.9 after horizontal demeaning. This is ratio of depth-averaged plane RMS values, not a global-volume RMS ratio. -1 indicates force diagnostic unavailable or zero pressure. Previous columns 1--10 are unchanged. Force diagnostic is evaluated on both ordinary-statistics and force-output schedules; force output files are written only on the latter.

Build with the platform MPI/HDF5 toolchain; compilers produce different executables. Always run an MPI smoke test before replacing a production binary.
